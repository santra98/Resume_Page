# Resume Page

A clean, professional HTML-based resume/portfolio webpage showcasing your professional experience, skills, projects, and education.

🌐 **Live Demo**: [View Resume](https://santra98.github.io/Resume_Page/)

## 📋 Features

- **Professional Layout**: Well-organized sections for About Me, Skills, Experience, Projects, and Education
- **Responsive Design**: Clean semantic HTML structure
- **Easy to Customize**: Simple HTML file with clear section organization
- **No Dependencies**: Pure HTML - no frameworks or build tools required

## 🚀 Setup Instructions

### Option 1: Direct File Access
1. **Clone the repository**:santra98
   ```bash
   git clone https://github.com/yourusername/Resume_Page.git
   cd Resume_Page
   ```

2. **Open in your browser**:
   - Double-click `index.html` to open it directly in your default browser, OR
   - Right-click `index.html` → Open with → Your preferred browser

**Live Server (VS Code Extension)**:
- Install "Live Server" extension in VS Code
- Right-click `index.html` → Open with Live Server

## 📝 Usage

### Customizing Your Resume

Edit `index.html` with your favorite text editor and update the following sections:

1. **Header Section**: Update your name and professional title
   ```html
   <h1>Your Name</h1>
   <p>Your Title | Your Specialty | Your Focus</p>
   ```

2. **About Me**: Write a brief professional summary

3. **Skills**: Add your technical skills and competencies

4. **Experience**: Update your work history with positions, companies, and dates

5. **Projects**: Showcase your key projects with descriptions and technologies

6. **Education**: Add your educational background

7. **Contact**: Add contact information as needed

### File Structure
```
Resume_Page/
├── index.html          # Main resume document

```

## 🔧 Customization Tips

- **Styling**: Add `<style>` tag in `<head>` for CSS customization
- **Links**: Add `<a>` tags to link to projects, GitHub, LinkedIn, etc.
- **Images**: Add profile photo with `<img src="path/to/image.jpg" alt="Profile">`
- **Colors**: Modify background and text colors via CSS

### Example: Adding CSS Styling
```html
<style>
    body { font-family: Arial, sans-serif; margin: 20px; }
    h1 { color: #333; }
    section { margin-bottom: 30px; }
</style>
```
